# Como contribuir

A liderança do SmartMall AI é de [@geraldojoao](https://github.com/geraldojoao).

1. Escolha e alinhe uma entrega no [Trello](https://trello.com/b/TMJ0EfTl).
2. Atualize sua main local e crie uma branch de tarefa, como `feat/FE-02-formulario`.
3. Faça commits com sua própria identidade Git e envie a branch.
4. Abra um pull request para `main`, preencha o modelo e vincule as evidências.
5. Aguarde a revisão de @geraldojoao e os checks exigidos.
6. A liderança integra a alteração após a revisão.

O [guia completo](https://github.com/SmartMall-AI/docs-smartmall-ai/blob/main/CONTRIBUTING.md) explica permissões, comandos e critérios de conclusão. O [contrato compartilhado](https://github.com/SmartMall-AI/docs-smartmall-ai/blob/main/contrato-api.md) orienta as integrações.

A main é protegida. A liderança possui uma exceção explícita à exigência de aprovação de PR para alterações de sua própria autoria; essa exceção não dispensa as verificações automáticas exigidas.
